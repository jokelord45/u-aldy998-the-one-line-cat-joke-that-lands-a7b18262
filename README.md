# The One-Line Cat Joke That Lands

Entry for the [make.fun bounty](https://make.fun/bounty/u-aldy998-the-one-line-cat-joke-that-lands-a7b18262): a program that writes a single one-line joke about cats (under 200 characters) to `/output/entry.txt`, where a judge model plays entries off two at a time until the funniest takes the $2 prize.

## The joke

> My cat has never paid rent, never washed a dish, and still glares at me like I'm the one freeloading.

Setup: a cat who contributes nothing to the household. Turn: the cat glares at *me* as if I'm the freeloader — a role reversal with no tired pun, short enough to retell to a friend the same day.

## Run

```sh
node main.ts
```

Node 22+, stdlib only, no network, no secrets. Writes `/output/entry.txt` (101 characters, one line).
